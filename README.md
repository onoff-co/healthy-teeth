# 건강니 치과

연두색과 하늘색으로 구성한 치과 포트폴리오 사이트. 외부 런타임 의존성 없이 Node.js 22 이상에서 실행합니다.

## 실행

```powershell
npm run dev
```

기본 주소: http://127.0.0.1:5183

```powershell
npm test
npm run build
npm run preview
```

다른 포트: `npm run dev -- --port 5184`. 빌드 산출물은 `dist/`. 상대 경로와 해시 라우터를 사용하므로 하위 디렉터리 정적 호스팅도 가능합니다.

## 페이지

- `#/`: 메인
- `#/about`: 치과 소개·공간·가상 위치
- `#/services`: 진료 안내
- `#/services/whitening`, `#/services/orthodontics`, `#/services/implant`, `#/services/general`: 진료 상세
- `#/booking`: 날짜·시간·진료 선택과 예약 접수 체험
- `#/reservations`: 이름·휴대폰 번호와 데모 인증번호로 예약자 확인 후 본인 예약 조회·취소·기록 삭제

모든 화면에 우측 하단 빠른 상담 버튼이 고정됩니다. 상담에서 진료를 고르면 예약 화면에 반영됩니다.

## 예약 범위

실제 치과에 전송되는 예약 서비스가 아닌 포트폴리오용 기능입니다. **가상의 이름과 연락처만 입력하세요.** 개인정보, 증상, 의료정보를 입력하지 않습니다.

- localStorage 키: `healthy-teeth-demo-reservations-v1`
- 동일 출처·브라우저 내 중복 시간 차단. 지원 브라우저는 Web Locks로 탭 간 접수를 직렬화합니다.
- 지난 시간, 일요일, 평일 점심시간, 60일 이후 예약 차단. 토요일 10:00~14:00, 평일 10:00~19:00.
- 운영 시간 계산은 방문자의 로컬 시간 기준입니다.
- 다른 기기 간 예약 공유, 실제 병원 접수, 문자/메일, 결제 기능 없음.
- 저장소 접근 불가·용량 초과·손상 시 오류를 표시하며 접수 성공을 표시하지 않습니다.
- 실제 서비스 전환 시 별도 서버·DB·한국 시간대 처리·관리자 권한·개인정보 처리 정책이 필요합니다.

## 이미지와 정보

`assets/`의 고유 AI 생성 이미지 네 장을 WebP로 최적화했습니다. 페이지 사이에 사진을 재사용하지 않습니다. 프롬프트와 배치는 `ASSET-PROMPTS.md` 참고. 로고·진료 아이콘은 코드로 작성한 SVG입니다.

치과 주소, 대표자, 전화번호, 사업자등록번호, 교통 정보는 모두 가상 데이터입니다. 진료 내용은 브랜드 소개용이며 효과·비용·기간을 보장하지 않습니다.

## 간편 예약자 확인

예약할 때 사용한 가상 이름·휴대폰 번호를 입력하고 `인증번호 받기`를 누르세요. 화면의 **체험용 인증번호** 6자리를 입력하면 두 정보가 모두 일치하는 기록만 표시됩니다. 취소·삭제도 해당 예약자에게만 적용됩니다.

- 실제 SMS 발송이나 본인 확인이 아닌 UI 시뮬레이션입니다. 브라우저 저장소는 암호화되지 않으므로 실제 개인정보나 진료정보를 저장하지 마세요.
- 인증번호는 화면에 표시되고 메모리에만 보관됩니다. 3분 만료, 재발급 대기 30초, 오입력 5회 후 새 번호 발급 필요. 재발급하면 이전 번호는 무효입니다.
- 조회 상태는 메모리에서 최대 10분 유지됩니다. 조회 종료·새로고침 후에는 다시 인증해야 합니다. 조회 상태나 인증 코드를 localStorage에 저장하지 않습니다.
- 실제 운영 시 화면에 코드를 표시하는 데모 모듈을 제거하고, 서버의 SMS 발급·검증 API, 서버 세션, 서버 측 예약 소유권 확인 및 요청 제한으로 교체해야 합니다.
